# AI Gym & Fitness Assistant

An AI-powered fitness assistant for workout tracking, diet planning, habit tracking, and fitness guidance.

## 🚀 Live Demo

**Frontend:**  
https://ai-fitness-assistant-tau.vercel.app/

**Backend API:**  
https://ai-fitness-assistant-ftc3.onrender.com

## ✨ Features

- 🏋️ AI workout & squat rep counting
- 🧮 BMI & calorie calculator
- 🥗 Diet plan & grocery list generator
- 🤖 AI Gym Buddy chatbot
- 📈 Fitness habit tracker
- 📷 AI pose detection using MediaPipe

## 🛠️ Tech Stack

- React + Vite
- FastAPI + Python
- MediaPipe
- Axios
- Vercel
- Render
